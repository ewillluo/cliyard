# Cliyard Web 页面方案

> 路径 C：以服务方式启动 cliyard，命令自动渲染为 Web 表单，执行过程以步骤流实时展示。
> 原型见「原型」Tab：**command-panel**（主界面，历史记录在右侧 tab 中）。

## 页面清单

| 页面 | 定位 | 原型 |
|---|---|---|
| 命令列表 + 表单 + 执行步骤/历史 | 主界面（三栏单页，历史在右侧 tab） | `command-panel` |

## 主界面布局（command-panel）

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏: cliyard-web · spec 目录 · 运行状态 badge · 历史/认证/设置     │
├─────────────┬──────────────────────────┬─────────────────────────┤
│ ① 命令树     │ ② 命令表单                │ ③ 执行步骤 │ 历史记录 (tab) │
│ · 搜索       │ · JSON Schema 自动渲染    │ · 参数校验 → 认证 → 请求  │
│ · 资源分组    │ · 类型/必填/枚举/密码框   │   → 响应 → 格式化 → 完成  │
│ · labels    │ · 执行 / 重置             │ · 每步直接输出执行结果    │
│   badge     │                          │ · 实时滚动（SSE）         │
│             │                          │ · 历史：表格 + 重放       │
├─────────────┴──────────────────────────┴─────────────────────────┤
│ 底部: 服务信息 · 统计                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## ① 命令树

- 左侧按资源分组（`repos`、`users`…），组内为命令（`list`/`create`/`delete`）
- 命令旁展示 `labels` badge（如 `[已调试]`、`[v2]`），与 `--help` 输出一致
- 顶部搜索框过滤命令；选中命令高亮，右侧联动渲染表单

## ② 命令表单（JSON Schema 自动渲染）

cliyard YAML spec 经转换器生成 JSON Schema，前端 `react-jsonschema-form` 渲染：

| spec 来源 | 表单表现 |
|---|---|
| `params.body/query/header` | 输入框 / 数字框 / 开关 / 数组 |
| `params.path` | 必填字段（带 `*`） |
| `enum` | 下拉选择 |
| `default` / 示例 | 预填默认值 / placeholder |
| `auth`（token/密码） | 密码框（`••••`） |

底部：**执行**（primary）、**重置**（outline）。

## ③ 执行步骤流（核心）

每次执行产生 6 步事件，SSE 实时推送，前端逐条渲染——**每一步直接输出执行结果**：

1. **参数校验** — 绑定后的最终参数（含默认值填充）
2. **认证准备** — 使用的认证方式 / profile / token 有效期
3. **发送请求** — method + 完整 URL + headers（代码块样式）
4. **等待响应** — HTTP 状态码 + 耗时
5. **格式化结果** — JSON / 表格输出预览
6. **完成** — 退出状态

- 进行中步骤显示呼吸点；失败步骤红色高亮 + 完整错误
- 步骤区顶部「重新执行」「复制」「清空」操作按钮

## 历史记录（command-panel 右侧 tab）

- 与执行步骤共用右侧面板，tab 切换：**执行步骤 | 历史记录**
- 表格：时间 / 命令 / 状态 / 耗时 / 操作
- 成功与失败用状态 pill 区分（成功绿 / 失败红）；操作列：**重放**
- 顶部「清空记录」「刷新」；分页展示

## 与方案文档的关系

- 执行引擎：进程内复用 cliyard（CliRunner + 输出捕获 → SSE）
- 转换器：`YAML spec → JSON Schema`（表单层唯一新增代码）
- 前端：React + `react-jsonschema-form` + Ant Design，静态资源由 FastAPI 托管
- 入口：`cliyard serve <spec-dir>`，浏览器自动打开
