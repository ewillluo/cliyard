# xiyucli

Generated by [cliyard](https://github.com/example/cliyard).

## Install

```bash
pip install -e .
```

## Usage

```bash
# Show available commands
xiyucli --help

# Authenticate (first time)
xiyucli auth add -n myenv -e <endpoint> -u <user> -p <pass>

# Or use an existing token
xiyucli auth add -n myenv -e <endpoint> -t <token>

# Run commands
xiyucli <resource> list --page-size 10
xiyucli <resource> list --format json
```

## Adding new resources

1. Create a YAML file in `src/xiyucli/specs/` (copy an existing one as reference):

```yaml
description: My resource
path: myresource
methods:
  list:
    http:
      method: GET
    output:
      items_path: $.items
      fields:
        - name: id
          alias: ID
  create:
    http:
      method: POST
    params:
      body:
        - name: name
          type: string
          required: true
```

2. Re-run `cliyard gen --name xiyucli` in the project directory to regenerate the CLI.

## Adding plugins

Create a `.py` file in `src/xiyucli/specs/plugins/`:

```python
from cliyard.plugin import register_auth_step, register_hook

@register_auth_step("custom_login")
class CustomLogin:
    def execute(self, auth_state, config, http_client):
        # Custom auth logic
        token = "my-token"
        http_client.default_headers["Authorization"] = f"Bearer {token}"
        auth_state["token"] = token
        return token

@register_hook("custom_hook")
def custom_hook(req):
    req.headers["X-Custom"] = "value"
    return req
```

Reference plugins in `_auth.yaml`:

```yaml
auth:
  steps:
    - name: login
      type: plugin:custom_login
```

## Custom method plugins

For business logic that involves multiple API calls, write a method plugin:

```python
# src/xiyucli/specs/plugins/my_biz.py
from cliyard.plugin import register_method

@register_method("multi_step_import")
def multi_step_import(params, http_client, config):
    # Step 1: prepare
    r1 = http_client.request("POST", "/api/prepare", data=params)
    # Step 2: transform and commit
    r2 = http_client.request("POST", "/api/commit", json=r1.json())
    return {"status": "done", "id": r2.json().get("id")}
```

Reference it in a resource YAML:

```yaml
methods:
  import:
    type: plugin:multi_step_import
    config:
      batch_size: 100
    params:
      body:
        - name: source
          type: string
          required: true
```

The plugin function receives ``params`` (validated CLI args), ``http_client``
(authenticated), and ``config`` (from YAML). The return value is JSON output.

## Multiple environments

```bash
# Add environments
xiyucli auth add -n dev -e https://dev.example.com -t <token>
xiyucli auth add -n prod -e https://prod.example.com -t <token> --default

# Switch between them
xiyucli auth switch prod
xiyucli --env prod <resource> list
```
